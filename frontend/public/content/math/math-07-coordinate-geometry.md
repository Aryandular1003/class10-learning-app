Chapter 7: Coordinate Geometry (Weightage: 7 Marks)
Cartesian Coordinate Formulas:
KEY FORMULA / RESULT: COORDINATE GEOMETRY FORMULAS
• Distance Formula: d = √[ (x₂ - x₁)² + (y₂ - y₁)² ]
• Distance of Point P(x, y) from Origin (0,0): d = √(x² + y²)
• Section Formula (Internal Division in ratio m₁:m₂): P(x, y) = ( (m₁x₂ + m₂x₁) / (m₁ + m₂), (m₁y₂ + m₂y₁) / (m₁ +
m₂) )
• Midpoint Formula: M(x, y) = ( (x₁ + x₂) / 2, (y₁ + y₂) / 2 )
• k : 1 Ratio Method: Coordinates = ( (kx₂ + x₁) / (k + 1), (ky₂ + y₁) / (k + 1) ). Set x = 0 for y-axis division, y = 0 for
x-axis division.
