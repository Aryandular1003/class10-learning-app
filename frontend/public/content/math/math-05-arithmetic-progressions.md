## SECTION 2: Complete Syllabus-Aligned Revision Notes & Formulas

Chapter 5: Arithmetic Progressions (AP) (Weightage: 6 Marks)
General AP Structure: a, a+d, a+2d, a+3d, ... where a = first term, d = common difference = a₂ - a₁.
KEY FORMULA / RESULT: ARITHMETIC PROGRESSION KEY FORMULAS
• n-th Term Formula: aₙ = a + (n - 1)d
• n-th Term from the End: aₙ' = l - (n - 1)d (where l = last term)
• Sum of First n Terms: Sₙ = (n / 2) [2a + (n - 1)d]
• Sum when Last Term (l) is Known: Sₙ = (n / 2) [a + l]
• Relation between Sₙ and aₙ: aₙ = Sₙ - Sₙ₋₁
